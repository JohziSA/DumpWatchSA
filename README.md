# Watch SA

Spot it. Snap it. Help clean it up.

South Africa’s simple way to report the messes that keep coming back — illegal dumping and broken water infrastructure — all in one app.

![Watch SA demo](./assets/demo.gif)

## Two watches. One place.

**DumpWatch SA**  
Catch rubbish, rubble and waste dumped where it doesn’t belong. Record a quick 5-second clip, snap the car, the person (if safe), and the number plate. Add a title and location. That’s it.

**WaterWatch SA**  
Flag leaks, dry taps, floods and overflowing sewers. One short video (or just a photo) plus a short description. No plate needed.

## How it works

1. Open the app and choose DumpWatch or WaterWatch  
2. Hit the big post button  
3. Capture the evidence  
4. Drop a title, street and province  
5. Submit — your post goes live on the public feed after a quick review  

No account. No login. Just a local display name and a feed that lives on your phone.

## Earn when it matters

- DumpWatch posts can earn **up to R300**  
- WaterWatch posts can earn **up to R20**  

Rewards only unlock once a report is proven true and leads to real action. Until then your balance stays at zero — no fake money, just real results.

## Browse the country

Filter by any of South Africa’s nine provinces or see everything at once. React with up to five emojis. Check prosecution status. Request deletion if needed.

Sample posts from Diepsloot, Soweto, eThekwini, Gqeberha and more are already loaded so the feeds aren’t empty on first open.

## Built for the phone in your pocket

Everything stays on your device. Light or dark mode. Your own reports under Profile. No server, no accounts, no friction.

**Watch SA** — because clean streets and working taps shouldn’t be optional.

## Run it

This is an [Expo](https://expo.dev) app (SDK 57) using Expo Router.

```bash
npm install
npx expo start
```

`npm run web` opens it in a browser. `npm run android` and `npm run ios` build the native apps.
